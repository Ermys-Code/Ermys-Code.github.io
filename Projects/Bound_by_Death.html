The Game

Bound by Death is a third-person hack and slash cooperate game developed in C++ using a custom engine. The project focuses on asymmetric character gameplay, enemy combat, level progression, environmental interaction, and audiovisual feedback through VFX and SFX.

The game is designed as a 2 player cooperative experience, where each player has a its own set of abilities and gameplay.

It features 3 unique levels, where you can find puzzles, traps, 5 different types of enemies, a mini boss and the final boss with 2 phases.

What I Did

During the Master's Degree, I focused on the graphics, developing, testing and implementing different graphical aspects.

This is the list of task that I did during the project:

  • Physically-Based Rendering
  • Diffuse / Specular Image-Based Lighting
  • Support for HDR skybox textures
  • Refactorize HLSL files to centralize reused code
  • Deferred Rendering Pipeline
  • Damage visual effect
  • Dissolve visual effect
  • Spectral visual effect
  • Upgrade outline Post Process effect

The Project

This project was made for my Master's Degree in Advanced Videogame Programming, where a 18-person team worked together to biuld from scratch this game and the engine where it runs, all this using C++ and DirectX 12.

We divided the tasks in different areas, like engine programming, gameplay programming, game design, level design..., and each person choosed what task to do.
